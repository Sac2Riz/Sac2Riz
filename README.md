# Sac2Riz

Jeux de logique à chiffres (sudoku et variantes, chiffres casés…) sous forme d'application web
progressive : installable sur tablette, 100 % hors ligne, sans publicité ni pistage.

## Démarrer

Prérequis : [Node.js](https://nodejs.org/) LTS (≥ 22.18).

```sh
npm install      # installe TypeScript (outil de développement uniquement)
npm run dev      # compile en continu et sert l'appli sur http://localhost:8080
npm run build    # compilation complète dans dist/
npm run check    # vérification des types + tests
```
